Usage

Import VerbenDatePickerModule from verben-ng-ui. Out of the box it is a normal date picker. It changes what it picks in two ways:

  • You set mode to 'range' or 'preset'.
  • The user switches inside the popup when you pass several [modes]. Their current value stays until they pick something new.
ModeA click…ngModel value
singlepicks the day and closes"2026-10-07T00:00:00"
range1st = start, 2nd = end, then closes["2026-10-01T00:00:00", "2026-10-07T23:59:59"]
presetpicks a whole period and closessame as range (preset id in selectionChange)

The previous picker, <app-date-picker>, is still available as Date Picker (classic).

Built-in quick choices

Week, month, quarter and year choices are calendar based: "Last 2 months" means the two complete months before this one. "Last N days" is rolling and includes today. The default list shows at most four per tab; the rest can be added with [presets]. The last column shows what each means today (weeks starting Monday).

Alternative: simple picker compare

<verben-simple-date-picker> is a second design built next to the one above, so the two can be compared before choosing. Instead of Date / Range / Periods tabs it has:

  • a Range checkbox: unticked picks one day, ticked picks a start and an end day (in either order);
  • a preset combobox: click it to see every preset tagged Daily / Weekly / Monthly / Quarterly / Yearly, or type to filter. It also understands presets that aren't in the list, such as “last 5 months”, “past two quarters”, “Q2 2025”, “march 2026”, “2024” or “ytd”. Arrow keys + Enter work; Esc closes the list.

It uses the same calendar, presets and value format, and lives in its own VerbenSimpleDatePickerModule, so either design can be dropped later.
