ngModel: {{ dueDate | json }}

Usage

Import DatePickerModule and FormsModule. ngModel receives a local date string without a time zone ("2026-10-05T00:00:00"); (dateChange) gives a Date.

  • Clicking a day sets the value and closes the popup.
  • With showTime, the popup stays open so the time can be adjusted; every change saves immediately.
  • In range mode the first click sets the start, the second the end. Ranges cover whole days.

Examples

ngModel: {{ meeting | json }}
ngModel: {{ period | json }}
range: {{ range?.[0] | date: 'medium' }} → {{ range?.[1] | date: 'medium' }}
