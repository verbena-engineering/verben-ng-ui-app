2. Sort Table Unification

verben-sort-table has been upgraded to natively accept both [sortOptions] (the classic SortTable interface) and [columns] + [data] (the DataSort interface).

Key improvements include:

  • High-Visibility Drag Handle: The reorder drag handle icon has been updated with a clear, crisp color (#64748b) and full opacity, making it easily distinguishable.
  • Dual Emission: When sorting is applied, both (selectedOptions) (classic IDataFilter[]) and (sortApplied) (SortCondition[]) are emitted.
  • Reset Synchronization: Resetting emits both (resetSortData) and (resetFilter).
