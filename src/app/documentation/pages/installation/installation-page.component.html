1. Install the package

The library needs Angular CDK for its overlays (date picker, dropdown, popups).

2. Add styles and icons

In angular.json, load the overlay CSS and the theme before your own styles so you can override tokens, and copy the icon assets to assets/lib-icons (that's where <verben-svg> looks for them).

3. Configure the root module

VerbenUiModule.forRoot() is optional. Anything you leave out keeps the default from theme.css. See Theming for every option.

4. Import a component module and use it

Each component ships in its own NgModule. Import the ones a feature needs (plus FormsModule for [(ngModel)]).

Working on the library

In this repo the docs app imports the built library from dist/, so run the library build in watch mode next to the dev server.

💡 Change not showing up? ng serve caches the built library. Stop and restart npm start after a library rebuild.
