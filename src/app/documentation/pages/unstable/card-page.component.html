Usage

Each part is optional and can appear in any order and any number of times. Two shortcuts keep templates short: <vbn-card title="…"> renders a header for you, and <vbn-card-header avatar title="…"> adds an avatar with initials.

Coming from <verben-card>

Existing markup works as it is: <vbn-card> takes the same inputs (pd, bgColor, width…) and the same card-header / card-body / card-footer slots. Rename the tag, import UnstableCardModule next to CardModule, done. Your own classes keep winning over the card's styles.
